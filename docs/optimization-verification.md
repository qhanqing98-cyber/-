# 稳定性与流畅度优化验证

验证日期：2026-10-05。保留原角色、莫奈配色与提醒式学习。

## 完成内容

- 原始 GIF 保持缓存；反向帧与程序生成的互动帧按需生成，共享 8 MiB 的最近使用缓存。
- 可见状态相同时跳过绘制与像素转换；位置变化直接移动已上传的窗口画面。
- 区分角色移动边界与画布位置，允许邻接显示器间连续移动；边缘卡片与面板重新定位。
- 提醒使用独立单调时钟。短卡顿计入时间；至少 5 秒的阻塞、菜单关闭、对话框返回后重新等待完整间隔，不推进词库。
- 面板显示安静、今日暂停或剩余分钟，切换模式时显示简短反馈。

## 测量

| 项目 | 结果 |
|---|---|
| 同一组素材优化前动画像素缓存 | 151.86 MiB |
| 优化后启动动画像素缓存 | 41.61 MiB |
| 遍历全部动作和方向后的峰值缓存 | 49.61 MiB |
| 首次生成互动帧及反向帧 | 0.641–0.891 ms |
| 相同画面连续调用 100 次，原像素比较路径 | 78.481 ms |
| 相同画面连续调用 100 次，跳过像素转换路径 | 0.035 ms |

数字来自本机单次基准，详见 `artifacts/optimization-benchmark.json`。内存数字只统计动画像素缓存，
不代表整个进程；静态调用基准不代表整程序 CPU 降幅。启动仍需要解码原始 GIF，约 3 秒。

## 如何复查

```powershell
.\.venv\Scripts\python -m unittest discover -s tests -v
.\.venv\Scripts\python tools\benchmark_optimization.py
.\.venv\Scripts\python tools\preview_optimization.py
```

自行退出正在运行的桌宠后，可在真实 Windows 桌面运行 `tools/smoke_exe.py`，
验证新版 EXE 的启动、托盘隐藏与恢复、安静模式和退出。脚本只操作自己启动的实例，使用临时数据。

函数说明、基础语法、数据流和设计决策见 [代码导读](code-guide.md)。
