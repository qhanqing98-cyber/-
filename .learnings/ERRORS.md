# Project learnings
2026-10-01: Large multi-file apply_patch calls reported a later failure after applying earlier files. Re-read current state before retrying; use separate file updates. A refactor string replacement also matched deeper indentation; use newline-anchored matching or AST-aware edits.
2026-10-01: PyInstaller inspected an inaccessible, unused user site-packages directory. Verified local bindepend code includes user-site paths even inside a venv. Isolate PYTHONUSERBASE and PYINSTALLER_CONFIG_DIR within build/ for validation; do not alter permissions or installed packages.
2026-10-02: Native tray creation fails on the isolated test desktop because Shell_TrayWnd is absent. Verified the same implementation on the real desktop: icon, callbacks, hotkey, recovery, and resource cleanup pass. Explicitly skip this test without a taskbar; do not weaken its assertions.
2026-10-02: SDL did not recognize synthetic WM_KEYDOWN messages with a zero scan-code field. The packaged smoke test passes when MapVirtualKeyW supplies the scan code and key-up state bits. This was a test-input issue, not a runtime keyboard defect.
2026-10-02: A repeated petting animation can have identical frames at quarter-cycle sample points. Check variation across the complete sequence, using hashes to keep assertion failures compact, instead of assuming every sampled frame must differ.
