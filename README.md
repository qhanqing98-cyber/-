# DeskPet 桌宠

Windows 桌面宠物，支持 GIF 动画、状态互动、多单词本学习和单文件 EXE 打包。

## 开发运行

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

也可以双击 `run_pet.bat`。右键宠物打开菜单；菜单支持方向键和 Enter；单词卡片支持鼠标点击、空格或 Enter 切换。

### 键盘交互

键盘操作要求桌宠窗口持有焦点：**先用鼠标点一下宠物本体**（悬停时会提示"点击桌宠启用键盘操作"），之后即可：

- `F` 喂食 · `P` 摸摸 · `空格` / `Enter` 逗它开心
- `方向键` 或 `WASD` 移动宠物
- `H` 隐藏宠物 · `Q` 开关安静模式
- `Esc` 收起菜单、面板或单词卡片；退出请使用右键菜单或托盘中的“退出桌宠”

### 托盘、暂停与互动

鼠标移到角色上时会暂停走动，并显示带有“喂食 +15”按钮的状态面板。
直接点击按钮即可喂食，无需先打开菜单或激活键盘；移向按钮时面板会暂时保留。
按下后移出按钮再松开会取消喂食。原有右键菜单和 F 快捷键仍可使用。

任务栏通知区域中有桌宠图标（可能收在隐藏图标区域）。单击图标切换隐藏/显示，
右键可以恢复到鼠标所在屏幕中央、暂停学习、开关安静模式或保存退出。
`Ctrl+Alt+H` 是全局隐藏/恢复快捷键；被其他程序占用时，仍可以使用托盘。
恢复显示不会自动抢走正在输入的键盘焦点。

- **安静模式**：停止自动走动和单词提醒，仍可主动喂食、抚摸或拖动；饱食、心情和精力仍正常更新。
- **暂停学习 30 分钟**：按实际时间计时，重启程序后仍保留截止时间。
- **今日不再提醒**：暂停到本地日期变更；托盘中的“恢复学习”可提前取消暂停和安静模式。
- **全屏时自动隐藏**：默认关闭，可以从托盘主动开启。全屏期间暂停学习提醒，桌宠继续可见。
  开启自动隐藏后，退出全屏恢复；普通带任务栏的最大化窗口不触发。
  全屏期间可通过托盘或快捷键手动恢复，直到结束这次全屏。
- **暂停或隐藏**：收起已有单词卡片，不推进学习位置；恢复后等待一个完整提醒间隔。

左键按下时先等待，移动达到 8 像素才开始拖动；松开时才确认点击。
拖动不会额外增加点击心情。点击呈现开心跳起、抚摸呈现摸头、拖动呈现提起动作。
这些动作基于当前角色生成，保留原有角色与柔和配色；`gifs/happy.gif`、
`gifs/petting.gif`、`gifs/lift.gif` 存在时优先使用对应自定义动画。

托盘和全局快捷键都无法提供恢复入口时，宠物保持可见，避免隐藏后找不到；
临时故障不会修改你的全屏隐藏偏好。Windows 资源管理器重建托盘后会尝试恢复图标。

## 打包

```powershell
.\.venv\Scripts\python build.py
```

生成文件位于 `dist\DeskPet.exe`。首次启动时，内置词库会复制到 `%LOCALAPPDATA%\DeskPet`。
旧版本 EXE 旁的存档和词库会复制到新目录，保留原文件，已有新存档不会被覆盖。
如需便携模式，在 EXE 旁创建空文件 `portable.flag`，数据就保存在 EXE 旁。

## 数据与性能

- `words_书名.json`：词库内容，只在导入或修改内容时写入。
- `progress\words_书名.json`：当前位置，每次切词只保存这个小文件。
- `words_index.json`：当前单词本和词库目录，切词时不重写。
- `save.json`：宠物状态，每 30 秒和退出时原子保存。单词间隔设置会立即保存。
- `settings.json`：安静模式、全屏隐藏偏好和提醒暂停时间；修改后原子保存，失败后重试。
  手动隐藏状态不跨重启保留。
- `crash.log`：错误日志，单个文件最多 1 MB，保留两份滚动日志。

损坏词库会生成 `.corrupt.bak` 备份，并禁止自动覆盖原词库。可修复原文件后重启，
或重新导入；同名导入会生成 `书名 (2)`。写盘失败时显示提示，未保存进度会重试。
旧词库文件中的 `index` 在没有独立进度文件时仍用于恢复，不需要手动转换。

空闲使用 30 帧，拖动和粒子反馈时使用 60 帧，隐藏时使用 5 帧并跳过宠物更新和绘制；
GIF 读取自身帧时长，播放速度保持一致。
卡片文字和面板使用有数量上限的缓存；反向帧和互动帧按需生成，共享 8 MiB 缓存。
可见内容未变化时跳过绘制和像素转换；只移动位置时复用已经上传的画面。
角色按所在显示器的工作区域限制位置，邻接显示器之间可以连续走动；画布另行定位，
让边缘的菜单、状态面板和单词卡片保持可见。窗口创建前启用 DPI 感知。
单词卡片以外的透明区域仍允许点击下面的桌面。

提醒使用独立的实际时间，动画仍限制单帧补偿以避免突然跳跃。短卡顿计入提醒时间；
长时间阻塞（至少 5 秒）、菜单关闭或对话框返回后重新等待完整间隔，不跳过当前单词。
状态面板显示“安静中”“今日暂停”或暂停剩余分钟，切换模式时有简短反馈。

## 验证与阅读代码

```powershell
.\.venv\Scripts\python -m unittest discover -s tests -v
.\.venv\Scripts\python tools\benchmark.py
.\.venv\Scripts\python tools\benchmark_optimization.py
.\.venv\Scripts\python tools\preview_interactions.py
.\.venv\Scripts\python tools\preview_optimization.py
```

测试中的主循环使用隐藏窗口和临时存档目录。基准测试只在临时目录写入，不修改你的学习资料。
原生托盘测试需要真实 Windows 任务栏；隔离桌面没有任务栏时明确跳过。
互动预览输出到 `artifacts/interaction-preview.png` 和 `.gif`，不读取用户存档。
打包后可运行 `python tools/smoke_exe.py` 验证启动、托盘隐藏/恢复、安静模式和退出；
该检查需要真实 Windows 桌面，使用临时数据，有已有桌宠实例时拒绝操作。
